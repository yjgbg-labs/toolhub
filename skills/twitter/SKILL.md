# Twitter

通过 FxTwitter 官方公共实例只读访问 X/Twitter 公开数据。仅处理公开内容的查询与整理；发布、点赞、关注、私信、登录和修改账号不属于本 skill。

## 固定入口与安全边界

- **API 基址与版本前缀**：`https://api.fxtwitter.com`，当前版本前缀为 `/2/`。
- **动态规范入口**：接口文档索引 `https://docs.fxembed.com/api/twitter/`，OpenAPI 规范 `https://api.fxtwitter.com/2/openapi.json`，服务状态页 `https://status.fxtwitter.com`。
- **免鉴权约束**：公共实例读取无需 API key，严禁向用户索取 X 账号密码、Cookie、`auth_token` 或 `ct0`。

## 核心路径、分页与限流参数

- **基础资源路径**（拼接在基址之后）：
  - 单条推文：`/2/status/{id}`（从推文链接 `/status/` 之后提取纯数字 ID）。
  - 用户资料：`/2/profile/{handle}`（去除开头的 `@`）。
  - 作者线程：`/2/thread/{id}`。
  - 完整对话与回复：`/2/conversation/{id}`。
  - 搜索、趋势、时间线、媒体与互动列表等扩展路径不在此硬编码，统一先从接口文档索引或 OpenAPI 规范动态查阅路径与参数名。
- **参数编码与校验**：动态查询词（含空格、`#`、`&` 或非 ASCII 字符）写入查询参数前必须严格做 URL 编码；同时核验 HTTP 状态码与返回 JSON 顶层的 `code` 字段，两者均成功才视为有效结果。
- **游标分页**：列表响应包含 `cursor.top` 与 `cursor.bottom`，请求下一页时将 `cursor.bottom` 传入 `cursor` 参数；按需拉取最少页数，不盲目遍历全量时间线或关系链。
- **速率限制**：API v2 按来源 IP 限制为每分钟 `1000` 次请求；收到 `429` 时立即停止并告知限流，禁止并发重试或切换代理绕过。

## 结果整理与失败处理

- 优先引用响应中的 `status.url`、handle、推文 ID 与精确发布时间，明确区分正文、引用推文、回复、转推与附件媒体（不主动下载大体积媒体文件），忠实保留原帖语气与不确定性，事实核查须依赖独立信源；分页查询须注明覆盖范围及是否仍有后续页。
- **状态码处理**：`404` 或 tombstone 结合响应中的 `reason` 区分删帖、私密、封禁或屏蔽；`401` / `403` 直接报告公共实例无法读取；`5xx` 结合状态页区分上游故障，不误报为内容不存在；文档与实际返回不一致时以实时 OpenAPI 与响应为准。
