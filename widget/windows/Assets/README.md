# OpenCode icon

`opencode-black.png` is the unmodified `opencode-logo-light-square.png` download from
[OpenCode's official brand page](https://opencode.ai/brand), retrieved 2026-11-01.
The "light" asset is the black mark intended for light backgrounds.

`opencode-black.ico` contains 16, 20, 24, 32, 40, 48, 64, 128 and 256 pixel versions
of that image for Windows Explorer, the application and the notification area.
The original colors and transparent background are preserved.
