# OpenCode icon

The application and notification area use OpenCode's black-backed website icon:
a black outer background, a white frame, and a black/dark-gray interior.

`opencode-site.png` is the unmodified
[`web-app-manifest-512x512.png`](https://opencode.ai/web-app-manifest-512x512.png)
from OpenCode's official website, retrieved 2026-11-18. It is the high-resolution
version of the [`apple-touch-icon-v3.png`](https://opencode.ai/apple-touch-icon-v3.png)
preview selected for the widget.

`opencode-site.ico` contains 16, 20, 24, 32, 40, 48, 64, 128 and 256 pixel versions
for Windows Explorer, the application and the notification area. The original
colors and opaque black background are preserved.

## Previous transparent variants

`opencode-white.png` is the unmodified `opencode-logo-dark-square.png` download from
[OpenCode's official brand page](https://opencode.ai/brand), retrieved 2026-11-11.
The "dark" asset is the white mark intended for dark backgrounds.

`opencode-white.ico` contains 16, 20, 24, 32, 40, 48, 64, 128 and 256 pixel versions
of that image for Windows Explorer, the application and the notification area.
The original colors and transparent background are preserved.
